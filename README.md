## 🌟 Key Features

- **Atmospheric 3D Scrollable Background**: Custom procedural Three.js WebGL scene featuring a fluid undulating wave ribbon mesh, wireframe orbitals in deep space, and an ambient stardust field that responds to scroll and mouse movement while preserving 100% text legibility.
- **Dual Theme Architecture (Dark & Light Mode)**: Full-fidelity design system with high-contrast typography, frosted glass surfaces, and tailored color tokens across both themes with `localStorage` persistence.
- **Scrolled Glassmorphism Navbar**: Dynamic floating navigation capsule with active section tracking, mobile slide-out drawer, and instant theme toggling.
- **Interactive 3D Bento Grid & Photo Showcase**: Dynamic identity card with interactive tab switching (profile view & live developer terminal telemetry), degree credential badges, and photo switcher.
- **Interactive Deep Architecture Modals**: Comprehensive technical decision logs, dependency graphs, and architecture specifications for each project.
- **WCAG AAA Contrast Compliance**: Crisp typography (`#ffffff` primary, `#cbd5e1` secondary in Dark Mode; `#0f172a` primary, `#334155` secondary in Light Mode).

## 💻 Getting Started Locally

### Prerequisites
- Node.js (version 20.19.0 or higher)
- npm (version 10.0.0 or higher)

### Installation
```bash
# 1. Clone the repository
git clone https://github.com/mohammad-rabius-sani/<repo-name>.git

# 2. Navigate to project directory
cd <repo-name>

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev
```

The application will be running at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
Generates optimized production assets in the `dist/` directory.
